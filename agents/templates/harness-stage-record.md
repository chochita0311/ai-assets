# Private Harness Stage Record

Use the [ordinary stage operation](../operations/harness-improvement.md#ordinary-stage-work)
and [evidence policy](../policies/harness/harness-improvement.md#evidence-of-application).
Save at the resolved private stage owner. Use one identity per real stage
attempt; append recovered or later evidence with its actual observation time.
With a ready binding, save or reuse this stage at entry before performing the
role, then persist its target pointer when existing audience-safe task references
do not suffice. At the real closing boundary, save the stage before refreshing
that pointer with the saved state, even when no Improvement Record is warranted.
Use `unknown — reason` for unavailable facts. Do not create a full experiment
just because this record exists.
