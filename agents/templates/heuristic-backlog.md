# Heuristic Backlog Template

## Metadata
- ID: `heur-0000`
- Status: `draft`
- Feature: `[feat-0000-title](../feature/feat-0000-title.md)`
- Spec: `[spec-0000-title](../spec/spec-0000-title.md)`
- Created: `YYYY-MM-DD`
- Updated: `YYYY-MM-DD`

## Pending Suggestions
- Record non-blocking heuristic suggestions with:
  - originating run ID and relative run link
  - attempt when relevant
  - execution profile
  - surface lane when relevant
  - source evaluation link
  - severity
  - summary
  - rationale
  - possible future feature or planning target
- Preserve this provenance when promoting an item. If the backlog is run-local, shared provenance may live in metadata; a backlog spanning runs must retain it per suggestion.

## Promoted Items
- Record suggestions that were later promoted into planning work.

## Continuity Notes
- Add dated notes when backlog status changes materially.
