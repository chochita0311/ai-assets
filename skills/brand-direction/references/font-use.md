# Choosing type for a commercial product

Separate type seen in a reference, type used to render the specimen, and font software that will travel with the product. A foundry specimen can inform proportions or spacing without supplying a font file.

- Identify the face, source, style or variable axes, exact file or release, and intended uses. Distinguish a local comp from a public preview, self-hosted web use, and embedding or redistributing a font in a paid native app. A desktop, trial or web license may cover only some of these.
- Check the original distribution's license or foundry agreement for that face and medium. Some libraries distribute multiple licenses. Check redistribution, required copyright notices, file conversion or subsetting, reserved names, and applicable seat, domain or usage limits where relevant. A local installation or a free download establishes availability only.
- If the intended rights are clear, keep the source URL, version or fingerprint, allowed use and any obligations with the specimen or handoff. Include required notices with distributed files. If a chosen face requires an unconfirmed purchase or permission, keep it as a visual reference and render the deliverable with a suitable cleared face. Record what would need to change to adopt the original.
- Render the replacement with representative words, figures and the target writing systems. Check its proportions and line breaks again. A CSS font list can silently fall back for an entire script. Distinguish an installed system fallback from font binaries bundled in the product.
