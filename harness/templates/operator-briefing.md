# Operator Briefing Template

Use only the form required by the active trigger. Omit empty sections, combine adjacent sections when prose reads better, and never expose this scaffold mechanically.

## Orientation Brief

```markdown
## Current Direction

<Explain the active destination and the current position in two or three connected sentences.>

### Available Next Work

<Explain the most relevant next work and why it is ready.>

### Not Ready Yet

<Explain material blocked work, the missing decision or evidence, and why that matters.>

### Human Review

<State what is due now or the event that should bring it back. Omit when none.>
```

## Work Briefing

```markdown
## Work Briefing

<Situation: explain the larger objective and the prior events needed to understand this target.>

<Current state: explain what is complete, partial, failed, deferred, or unproven and define material terms.>

<Why now: explain why this target is the appropriate current step.>

### This Work Will

<Explain the intended change or investigation.>

### This Work Will Not

<Explain nearby decisions, claims, approvals, or scopes that remain unchanged.>

### Human Review

<State whether a decision is required now, later at a named trigger, or not at all.>

### Canonical References

<Link only the small set of owner artifacts useful for audit.>
```

## Direction Alert

```markdown
## Direction Alert

Previous direction:
<Explain the relevant existing rule or assumption.>

New input or evidence:
<Explain what changed or conflicts.>

Impact:
<Explain the affected target, scope, evidence, safety, or authority.>

Required route:
<State whether work can continue, must narrow, or must return for a decision.>
```

## Review Receipt

```markdown
## Review Receipt

### Established

<Explain the result and the exact boundary in which it holds.>

### Still Open

<Explain unresolved matters and why the completed work did not resolve them.>

### Direction And Assumption Delta

<Explain new, changed, or invalidated direction and assumptions. Omit when none.>

### Human Review

<State the concrete decision or inspection required now. If none, say when the matter should return.>

### Resume Trigger

<Name the event or evidence that should surface the matter again.>

### Canonical References

<Link the owner artifacts for audit.>
```

## Work Briefing Variation: Handoff Resume

Use this Work Briefing variation when a supplied handoff must be reconciled with current canonical state before work resumes.

```markdown
## Work Briefing

<Explain the objective in plain language.>

<Explain what happened before the handoff, including why the work stopped or remained partial.>

<Explain what the handoff still gets right.>

<Explain what changed after the handoff or which assumption is stale, including why it affects the next action.>

<Explain the safe current starting point and the concrete work to perform now.>

<Explain what this work will not establish or approve.>

<State whether the human must decide anything now or at a named later trigger.>

### Canonical References

<Link the current owners used to reconcile the handoff.>
```
